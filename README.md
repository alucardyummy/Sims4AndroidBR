# Sims4AndroidBR

## Visão Geral
O **Sims4AndroidBR** é um guia completo em formato de site que ensina como jogar **The Sims 4 no Android** utilizando o emulador **GameHub**.  
O projeto combina instruções passo a passo, vídeos demonstrativos, links de download e dicas de configuração para oferecer uma experiência clara e acessível.

## Estrutura
- **HTML**
  - Header com logo e navegação
  - Hero section com introdução e botão de início
  - Cards interativos que abrem modais explicativos
  - Seção de erros e bugs com acordeão de soluções
  - Rodapé com créditos e botão de compartilhar

- **JavaScript**
  - Controle de modais (abrir/fechar, preload de vídeos, histórico de navegação)
  - Player de vídeo customizado com barra de progresso, tooltip e aceleração por toque
  - Música de fundo e efeitos sonoros
  - Cursor customizado com partículas e animações
  - Easter egg interativo com corações e explosões gráficas
  - Toast de notificação para copiar link
  - Botão de voltar ao topo com animação
  - Acordeão para seção de erros, com carregamento inteligente de vídeos

- **CSS**
  - Estilo moderno com fundo escuro e cores turquesa
  - Cards com efeito de vidro e brilho animado
  - Modais com blur, transições suaves e estilos diferenciados para alertas/dicas/erros
  - Player de vídeo estilizado com botões customizados
  - Cursor customizado e partículas animadas
  - Responsividade para diferentes tamanhos de tela
  - Rodapé discreto e estilizado
  - Botão “Back to Top” com animação giratória
  - Seção de erros com acordeão estilizado e formulário de contato

## Funcionalidades
1. Guia de Download: links para apps necessários (1DM, ZArchiver, Cx Explorador, GameHub) e layouts compatíveis
2. Instalação: instruções para baixar o jogo base ou versão completa, com vídeos explicativos
3. Configuração: ajustes de FPS e demonstrações para diferentes versões do GameHub
4. Tradução: tutorial para aplicar tradução PT-BR no jogo
5. Mods: instruções para instalar CC e WickedWhims, incluindo links de tradução
6. Contêiner: explicação de como acessar interface de arquivos no GameHub
7. Erros & Bugs: seção com soluções para problemas comuns (cache corrompido, tela preta, etc.)
8. Extras: easter egg interativo, botão de compartilhar guia, toast de notificação, botão de voltar ao topo

## Requisitos
- Dispositivo Android com espaço livre suficiente (20–30 GB recomendados)
- Instalação do emulador **GameHub**
- Aplicativos auxiliares: **1DM**, **ZArchiver**, **Cx Explorador**
- Conexão à internet para baixar jogo, expansões, mods e traduções

## Organização de Arquivos
- `/index.html` — página principal do guia
- `/style.css` — estilos visuais e animações
- `/audio/` — arquivos de áudio (música de fundo, efeitos)
- `/img/` — imagens e ícones usados no site
- `/video/` ou links externos — vídeos demonstrativos

## Objetivo
Fornecer um guia prático e acessível para usuários que desejam rodar **The Sims 4 no Android**, com instruções claras, recursos visuais e suporte a problemas comuns.
