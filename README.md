# Sims4AndroidBR

## Visão Geral
O **Sims4AndroidBR** é um guia independente que ensina como jogar o **The Sims 4** em dispositivos Android utilizando o emulador **GameHub**.  
O projeto não é afiliado à EA/Maxis, mas mostra como rodar o jogo no celular de forma prática.

## Conteúdo
- Passo a passo para baixar os aplicativos necessários  
- Instalação do jogo base ou versão completa  
- Ajustes de desempenho no GameHub  
- Tutorial para aplicar tradução em português (PT-BR)  
- Instalação de mods e conteúdo personalizado (CC e WickedWhims)  
- Como adicionar expansões  
- Layouts otimizados para jogabilidade no celular  
- Guia para deixar o jogo totalmente em PT-BR  

## Requisitos
- Dispositivo Android com **64–128 GB de armazenamento** e **mínimo 6 GB de RAM**  
- Espaço livre recomendado: **20–30 GB**  
- Emulador **GameHub** instalado  
- Aplicativos auxiliares: **1DM, ZArchiver, Cx Explorador**

## Objetivo
Facilitar a vida de quem deseja jogar o **The Sims 4** no Android, oferecendo instruções claras, acessíveis e práticas.

## Aviso Legal
Este guia é um projeto independente e não possui vínculo com a EA ou Maxis. O conteúdo descrito é apenas um tutorial para emular o jogo em dispositivos Android.
